# 발로란트 전략 가이드 (Valorant Strategy Guide)

발로란트(Valorant) 게임의 요원, 맵, 전략을 한눈에 볼 수 있는 웹 기반 가이드입니다.

## 📄 페이지 구성

| 파일 | 설명 |
|------|------|
| [index.html](index.html) | 메인 랜딩 페이지 |
| [agents.html](agents.html) | 요원 데이터 관리 및 정보 |
| [maps.html](maps.html) | 맵 가이드 & 추천 요원 |
| [haven.html](haven.html) | Haven 맵 상세 전략 및 추천 |

## ✨ 주요 기능

- **요원 데이터 관리**: 요원별 역할, 능력, 정보 확인
- **맵별 추천**: 각 맵에 적합한 요원 추천
- **Haven 맵 집중 분석**: Haven 맵 전용 전략 가이드
- **다크 테마 UI**: 발로란트 공식 색상(#0F1923, #FF4655) 기반 디자인
- **반응형 디자인**: Tailwind CSS 활용, 모바일/데스크톱 지원

## 🛠 기술 스택

- HTML5
- Tailwind CSS (CDN)
- Google Fonts (Noto Sans KR, Gabarito, Inter)

## 🚀 사용 방법

1. 저장소를 클론하거나 GitHub Pages로 접속합니다.
2. `index.html`을 열면 메인 메뉴가 표시됩니다.
3. 원하는 페이지(요원 / 맵 / Haven)를 선택하여 이용합니다.

### 로컬 실행

```bash
# 단순 파일 열기
open index.html

# 또는 간단한 로컬 서버
npx serve .
```
